# Ledger Index

Read this index instead of a ledger. Open one ledger only when a row matches, then read `## Summary` and `## Recent` only.

| Ledger | Open only when |
| --- | --- |
| `memory/TASK_LEDGER.md` | A previous task id matters now |
| `memory/PROGRESS_LEDGER.md` | The last phase outcome matters now |
| `memory/DECISIONS.md` | A decision constrains this step |
| `memory/RISKS.md` | A blocker may already be recorded |
| `memory/ROADMAP.md` | The goal asks for optimization directions |

`memory/PROJECT_FACTS.md` is already in the orchestrate working set. Do not open it from here.

Older ledger text lives under `archive/ledgers/`. Open that only when the summary is not enough.
